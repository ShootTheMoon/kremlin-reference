# kremlin-reference

모스크바 크렘린 + 붉은광장을 **실측 1:1 로 모델링하기 위한 레퍼런스 팩**이다.
도면·치수표·분류 스크립트는 이 레포에 있고, 사진 **542장 / 1,452 MB** 는
[Releases](../../releases/tag/photos-v1) 에 나눠 올려 두었다.

사진을 레포에 넣지 않은 이유는 용량이 아니라 **성질**이다. 도면은
퍼블릭 도메인이고 한 번 받으면 바뀌지 않지만, 사진은 파일마다
라이선스가 다르고(CC0 ~ CC BY-SA 4.0) 큐레이션이 계속 바뀐다.
git 히스토리에 1.4 GB 를 영구히 박아 넣을 이유가 없다.

관련 레포 — [`kremlin-palace`](https://github.com/ShootTheMoon/kremlin-palace)
(대크렘린궁 절차 생성) · [`granovitaya-palata`](https://github.com/ShootTheMoon/granovitaya-palata)
(파세트궁 실내) · [`overdare-map-pipeline`](https://github.com/ShootTheMoon/overdare-map-pipeline) (반출 파이프라인)

### 바르테네프 도판이 왜 핵심인가

С.П. Бартенев, 『Московский Кремль в старину и теперь』 кн.1 (1912) 에는
**탑 18기의 입면·단면·평면 실측도가 сажень 축척자와 함께** 실려 있다.
크렘린 탑의 층별 높이·테이퍼·총안 간격을 숫자로 주는 공개 자료는
현재 이것 말고 찾지 못했다. 사진만으로는 못 뽑는 값들이다.

`drawings/bartenev-1912/INDEX.md` 에 도판 83장 전부의 캡션·건물·종류·가치가
정리되어 있고, `towers/` 는 같은 파일을 탑별로 다시 묶은 것이다(복사본이므로
용량만 늘고 새 정보는 없다 — 작업 편의용).

## 좌표계 규약

이미 만들어 둔 씬과 좌표를 맞추려면 그대로 쓰면 된다. 상세는
`docs/MEASUREMENTS.md`.

| 항목 | 값 |
|---|---|
| 앵커 | 크렘린 relation `1360641` 중심 **55.7516212 N, 37.6181220 E** |
| 축 | **+X = 동, +Y = 북, +Z = 위**, 단위 m |
| 지면 | z = 0 (성당광장만 z = 1.6) |
| lat/lon → m | φ=55.7516° 기준 1° lat = 111337.3 m, 1° lon = 62772.1 m |
| `yaw` | +X(동)에서 반시계로 잰 건물 주축 각(도) |

정교회 성당은 동쪽을 향하므로 **yaw 가 곧 제단(앱스) 방향**이다.

> ⚠ 사진 8뷰를 방위로 배정할 때 `front_azimuth = 공칭_정면_나침반방위 − yaw`
> 로 **yaw 를 반드시 빼야 한다.** 손으로 분류한 108장으로 검증하면
> 빼면 102장 일치, 안 빼면 43% 로 떨어진다. 구현은 `tools/sort_views.py`.

### 치수 신뢰도 표기

`measured` 문헌·도면에서 직접 / `counted` 세어서 유도 / `derived` 비례에서
유도(**교체 대상**). 현재 250 / 17 / 48 — measured+counted 가 79% 다.
`derived` 는 추정이므로 쓰기 전에 신뢰도를 확인할 것.

| `photos-palaces.zip` | 05 대크렘린궁 · 06 파세트궁 · 07 테렘궁 · 08 상원궁 · 09 아르세날 · 10 오루제이나야 | 579 MB |
| `photos-walls-towers.zip` | 11 성벽·여장 · 12 스파스카야 탑 | 260 MB |
| `curated-best.zip` | `_best` 125장 · `_best_ai` 51장 · `_contact` 콘택트시트 | 262 MB |

압축을 풀면 건물 폴더가 나오고, 그 안이 8뷰로 갈라져 있다.

```
01_우스펜스키_대성당/
  0_실측도면/  1_Top/  2_Left45/  3_Front/  4_Right45/
  5_Left/  6_Right/  7_Back/  8_Bottom/
  _indoor/     실내 — 외관 모델링에 안 쓴다
  _notphoto/   도해·판화·렌더 등 사진이 아닌 것
  _other/      크롭·디테일 — 뷰 배정 불가
  _unsorted/   미분류
```

**시작점은 `curated-best.zip` 안의 `_contact/index.html`** 이다. 브라우저로
열면 건물별 8뷰가 한 장에 보인다. 다만 콘택트시트는 사진을 상대경로로
참조하므로, **4개 zip 을 같은 폴더에 풀어야** 썸네일이 뜬다.

`tools/*.py` 도 같은 레이아웃을 전제한다. 레포를 클론한 뒤 사진 팩을
레포 루트에 풀면 경로가 맞는다(`.gitignore` 가 사진 폴더를 무시한다).

### 소련 1953년 도판에 대하여

『Русское зодчество. Выпуск 2』(М.: Госстройиздат, 1953) 는 1953년 간행물로
러시아·미국 어느 쪽에서도 **저작권이 만료했다고 단정할 수 없다.** 여기 올린
8장은 원서 도판 34장 중 크렘린 실측도면이 실린 것만 골라낸 것이고, 원본은
네크라소프카 도서관 전자열람실(`electro.nekrasovka.ru`)이 **전권을 공개**하고
있다. 조사·연구 목적의 인용으로 보지만 확정된 PD 는 아니므로, 상업적
재배포에는 쓰지 말 것. 문제가 되면 이 폴더만 지우면 되도록 따로 두었다.

### 모델링 결과물에 적용할 때

사진을 **보고 만드는 것**은 라이선스와 무관하다. 문제가 되는 건
사진을 **텍스처로 베이킹해 배포**하는 경우다. 이때는
`docs/SOURCES.txt` 에서 해당 파일 라이선스를 확인해야 한다.

> **NC(비상업) 에셋은 오버데어로 내보내지 않는다.** 오버데어는 UGC
> 게임 플랫폼이라 게시 자체가 비상업 조건에 걸리고, SA 는 파생물에
> 전염된다. 격리는 컬렉션 이름으로 하고, 익스포터가
> `크렘린_NC_*` 를 건너뛴다.

출처 표시는 `ATTRIBUTION.md` 에 모아 두었다.
